# CardFit 정책 결정 로그

## 목적

제품·계산 정책의 승인 상태를 개발 TASK 54개와 분리해 관리한다. 승인되지 않은 값은 구현 기본값이나 테스트 expected 결과로 확정하지 않는다.

## Decision 목록

| ID | 결정 | 상태 | 연결 TASK |
|---|---|---|---|
| DECISION-001 | Net Benefit 계산 정책 | Open/Blocked | COMMAND-003, TEST-002 |
| DECISION-002 | Golden Vector expected 결과 | Open/Blocked | COMMAND-003, TEST-002 |
| DECISION-003 | 동의·반출·관측 보존 정책 | Open/Blocked | DATA-003, API-004, NFR-004 |

## 운영 규칙

- 정책이 확정되면 해당 TASK의 Open Decisions와 Decision Log를 함께 갱신한다.
- 정책 미확정 상태에서는 임시값을 제품 동작이나 테스트 expected 값으로 고정하지 않는다.
- 정책 변경 시 영향받는 Contract·Logic·Test·NFR TASK를 재검토한다.
