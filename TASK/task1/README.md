## 상세 TASK 현황

| 구분 | 개수 |
| --- | ---: |
| 구현 TASK (`INFRA-001`, `SEC-001` 포함) | 52 |
| 사전 명세 TASK (`SPEC-001`, `SPEC-002`) | 2 |
| **확정 기준선 합계** | **54** |

`01`~`03` 문서와 Gantt는 확정 기준선 54개로 작성되어 있다. `INFRA-001`, `SEC-001`은 목록·DAG·Wave·Gantt·Milestone에 모두 편입됐다. 문서명을 변경하거나 TASK를 추가·삭제할 때는 `01`~`03`의 목록·의존성·Gantt를 함께 갱신하고 이 표의 개수도 동기화한다.
