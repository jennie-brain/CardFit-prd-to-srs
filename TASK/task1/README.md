## 상세 TASK 현황

| 구분 | 개수 |
| --- | ---: |
| 기존 구현 TASK 기준선 | 50 |
| 사전 명세 TASK | 2 |
| 추가 검토 TASK (`INFRA-001`, `SEC-001`) | 2 |
| **현재 task2 파일 합계** | **54** |

01~03 문서와 Gantt는 52개 기준선으로 작성되어 있다. `INFRA-001`, `SEC-001`은 현재 추가 검토 TASK이므로 기준선에 편입할 때 목록·의존성·Gantt를 함께 갱신한다. 문서명을 변경하거나 TASK를 추가·삭제할 때도 동일한 규칙을 적용한다.
