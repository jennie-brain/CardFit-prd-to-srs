## 공통 UI 상태 계약

- `loading`: 중복 제출을 막고 진행 중 작업과 취소·재시도 가능 여부를 표시한다.
- `empty`: 실제 데이터 없음과 조회 실패를 구분한다.
- `partial/stale`: 경고, 기준일, 계산 가능 여부를 함께 표시한다.
- `error`: 사용자 수정 가능 오류와 운영자 조치 오류를 구분하며 내부 stack을 노출하지 않는다.
- `unavailable`: AI·관측처럼 선택 기능이 불가능해도 핵심 결과는 유지한다.
- `success`: 다음 행동과 되돌리기·재계산 조건을 분명하게 제시한다.
