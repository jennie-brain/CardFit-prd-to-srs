## Acceptance Criteria (BDD/GWT)
### Scenario 1: 정상 연결
- Given: 최신·완전 데이터다.
- When: 온보딩에 진입한다.
- Then: 연결 상태와 다음 입력 단계가 명확하다.
### Scenario 2: 동의 만료
- Given: 동의가 만료됐다.
- When: 진입한다.
- Then: 계산 가능으로 오인시키지 않고 재동의/Mock 상태 안내를 표시한다.
### Scenario 3: 스코프 인지
- Given: 온보딩을 완료한다.
- When: 고지를 확인한다.
- Then: 카드 해지·전환 대행을 제공하지 않는다는 문구가 접근 가능하게 노출된다.
