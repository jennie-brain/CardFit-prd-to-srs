# GitHub Project 용 TASK — NFR-001 계산·근거 성능

## Summary
- 목적: 실제 M1 경로에서 계산 p95≤5초와 근거 미달 거부 p95≤500ms를 반복 측정한다.

- 테스트: TEST-002·003

## Scope
- In: 계산·근거 거부 경로의 부하 모델, 계측, 임계치 판정
- Out: M3 실제 내부망·Production Adapter 네트워크 SLA

## Task Breakdown
- [ ] 데이터 크기·동시성·warm/cold 조건을 명시한다.
- [ ] 계산과 Evidence 거부 경로의 부하 스크립트를 작성한다.

- [ ] p50·p95·p99와 실패율 보고서를 생성한다.

## Acceptance Criteria (BDD/GWT)
### Scenario 1: 계산 부하
- Given: 정의된 M1 카드·Rule·동시성 데이터셋이다.
- When: 계산 부하를 실행한다.
- Then: p95≤5초이고 timeout 결과는 성공으로 계산하지 않는다.
### Scenario 2: 근거 거부
- Given: 근거 6개 미만 계산이다.
- When: 반복 조회한다.
- Then: 거부 응답 p95≤500ms다.
