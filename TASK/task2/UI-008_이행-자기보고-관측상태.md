## Acceptance Criteria (BDD/GWT)
### Scenario 1: 최초 자기보고
- Given: 선택 후 30일이 지나 재방문했다.
- When: 항목별 응답을 제출한다.
- Then: 1회 저장 결과가 표시되고 재제출로 중복 집계하지 않는다.
### Scenario 2: 응답·관측 불일치
- Given: 자기보고 완료지만 관측은 확인 불가다.
- When: 상태를 본다.
- Then: 어느 한쪽을 오류로 덮지 않고 두 상태와 사유를 표시한다.
### Scenario 3: 유지 추천
- Given: 유지 카드가 계속 보유 중이다.
- When: 결과를 본다.
- Then: 유지 준수로 표시하고 행동 완주라는 표현을 사용하지 않는다.
### Scenario 4: 해지 상태 부재
- Given: 명시 상태 없이 관측 증거가 부족하다.
- When: 상태를 본다.
- Then: 확정 문구 대신 추정·판정 불가를 표시한다.
