# GitHub Project 용 TASK — UI-007 조합 선택·외부 이동 경계

## Summary
- 목적: 사용자가 추천안을 저장·확정하되 발급·해지 대행으로 오인하지 않고 카드사 공식 페이지 이동을 구분하게 한다.
- REQ: REQ-FUNC-009·010(M1 기준선)
- 구현 책임: UX-004의 결과 근거·선택·만료·외부 이동 flow 중 선택 행동 영역을 구현한다.

## References (Spec & Context)
- 로직: COMMAND-004, QUERY-002
- 테스트: TEST-003·005·006

## Scope
- 조합 선택 확인, 만료·중복·소유권 오류, 기준선 생성 결과
- 카드사 공식 링크와 외부 이동 경고
- 행동 경계 재설계와 신청서 작성·제출·해지 실행은 범위 밖

## Task Breakdown
- [ ] 선택 대상·시나리오·차액을 확인 Dialog에 표시한다.
- [ ] 선택 중 중복 제출을 방지하고 결과를 명확히 표시한다.
- [ ] 만료 후보는 재계산으로 유도한다.
- [ ] 외부 이동 전 대행 미제공·카드사 조건 재확인을 고지한다.
- [ ] `plan_selected` event에 시나리오·후보 ID를 기록한다.

## Acceptance Criteria (BDD/GWT)
### Scenario 1: 정상 선택
- Given: 유효한 변경 후보다.
- When: 저장·확정한다.
- Then: 선택 완료와 다음 행동을 표시하고 기준선 생성 성공을 반영한다.
### Scenario 2: 만료 후보
- Given: 후보가 만료됐다.
- When: 선택한다.
- Then: 실행하지 않고 재계산 안내를 제공한다.
### Scenario 3: 외부 이동
- Given: 카드사 신청 링크를 누른다.
- When: 이동 전 확인한다.
- Then: CardFit이 발급·해지를 대행하지 않음을 명시한다.

## Technical & Non-Functional Constraints
- 외부 링크는 허용된 카드사 도메인만 사용한다.
- 유지 결론 사용자를 선택률 분모에 포함하지 않는다.

- [ ] M1 선택 KPI 이벤트 정의와 일치한다.
