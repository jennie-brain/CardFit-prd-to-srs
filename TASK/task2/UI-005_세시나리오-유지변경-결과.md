## Acceptance Criteria (BDD/GWT)
### Scenario 1: 기본 결과
- Given: 세 시나리오 계산이 완료됐다.
- When: 결과에 진입한다.
- Then: `예상한 만큼 쓸 때`가 먼저 보이고 실제 적용 금액·결론·차액이 표시된다.
### Scenario 2: 탭 전환
- Given: LOW/HIGH 결과가 있다.
- When: 탭을 바꾼다.
- Then: 추가 API 계산 없이 독립 조합 또는 유지 결론을 표시한다.
### Scenario 3: 유지 결론
- Given: Net Benefit 임계 미달이다.
- When: 결과를 본다.
- Then: 변경 CTA를 강요하지 않고 현재 조합 유지 이유를 정상 결과로 표시한다.
