- 구현 책임: UX-002의 입력 구조와 오류 피드백을 form·Server Action 연결로 구현한다.

## Acceptance Criteria (BDD/GWT)
### Scenario 1: 한 번 입력
- Given: 예상금액을 SINGLE로 입력한다.
- When: 저장한다.
- Then: 추가 금액 입력 없이 세 시나리오 생성 준비가 완료된다.
### Scenario 2: 범위 오류
- Given: 최소>예상 또는 예상>최대다.
- When: 제출한다.
- Then: 저장·계산 없이 인라인 오류와 수정 위치를 표시한다.
### Scenario 3: 이력 부족
- Given: 과거 이력이 3개월 미만이다.
- When: 화면을 연다.
- Then: 임의 업계 평균 대신 빈 폼·비개인화 예시를 표시한다.

- 2026-08-27: 초기 금액은 비워 두고 `예시 금액 적용하기`를 선택한 경우에만 수정 가능한 비개인화 예시를 채운다. 단위별 입력 편의는 `10_시각_프로토타입_화면_명세.md` T9에서 별도 확정한다.
- 2026-08-27: 금액 입력은 만원 단위로 고정하고 전체 원 금액·필요 시 억 단위 표현을 병기한다. 원·만원·억원 전환 탭과 소수 입력은 사용하지 않으며 빠른 금액 추가와 모바일 숫자 키패드를 제공한다.
- 2026-08-27: 할부 정책 미정으로 프로토타입 입력에는 일시불·할부 옵션을 노출하지 않으며, 할부 지원을 암시하지 않는다.
- 2026-08-27: 다건 미래지출에 ONE_TIME·MONTHLY 형태와 연·월 시점을 입력한다. 증가·감소 직접 선택과 미정 `confidence` 입력은 제외하고, 비교 가능한 월평균 Fixture가 있을 때만 변화 방향·차액을 표시한다.
