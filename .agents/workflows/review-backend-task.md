# 백엔드 TASK 검토 워크플로

- SRS 밖 기능·서비스·정책이 추가되지 않았는가?
- 데이터 흐름과 보관 체계가 UI보다 먼저 정의됐는가?
- 조회와 쓰기가 독립 검증 가능한가?
- 고난도 작업끼리 결합해 복잡도가 상승하지 않았는가?
- 완료 조건마다 자동 테스트가 있는가?
- 인증·인가·소유권·입력 검증과 로그 마스킹이 있는가?
- AI 장애가 계산과 근거 제공을 막지 않는가?
- 로컬과 배포 DB가 같은 PostgreSQL schema·migration을 쓰는가?
- 무료 한도, 운영 비용과 중단 규칙이 반영됐는가?
- M2·M3 기능이 승격 조건 없이 M1에 포함되지 않았는가?

판정은 PASS, CONDITIONAL PASS, FAIL로 기록하고 각 지적에 SRS 또는 TASK 근거를 연결한다.
