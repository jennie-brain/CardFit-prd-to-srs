## Decision Log
- 2026-08-26: Step 5 온보딩 UX를 QUERY-001과 COMMAND-001/002 계약에 직접 연결.
- 2026-08-27: 이력 부족·로컬 시각 프로토타입 입력은 빈 값으로 시작하고, 사용자가 선택할 때만 수정 가능한 비개인화 예시를 적용한다. 출처·최신성·편향 검토 전에는 업계 평균으로 표현하지 않는다.
- 2026-08-27: `/plan`은 미래지출과 카드 조건의 2단계다. SINGLE을 기본으로 하고 RANGE는 선택 시 펼치며, 카테고리는 선택형 대분류와 `기타` 직접 입력으로 구성한다.
- 2026-08-27: 로컬 시각 프로토타입에는 할부 선택·개월 입력을 두지 않는다. 예상 지출 총액과 시기만 받고 할부 관련 조건은 결과의 미반영 항목으로 전달한다.
- 2026-08-27: 미래지출은 `한 번 쓰는 금액`과 `매달 쓰는 금액`으로 구분한다. 증가·감소는 직접 묻지 않고 비교 가능한 과거 월평균과 미래 월 금액으로 도출하며, 기준값이 없으면 방향을 표시하지 않는다.
- 2026-08-27: 입력 상한 수치는 미확정이므로 프로토타입에서 임의 안내하지 않는다. 빈 값·0원·음수·비숫자·RANGE 순서 오류만 검토한다.
