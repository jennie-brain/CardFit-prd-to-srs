## Acceptance Criteria (BDD/GWT)
### Scenario 1: 계산 부하
- Given: 정의된 M1 카드·Rule·동시성 데이터셋이다.
- When: 계산 부하를 실행한다.
- Then: p95≤5초이고 timeout 결과는 성공으로 계산하지 않는다.
### Scenario 2: 근거 거부
- Given: 근거 6개 미만 계산이다.
- When: 반복 조회한다.
- Then: 거부 응답 p95≤500ms다.
