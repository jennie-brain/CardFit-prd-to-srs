## Acceptance Criteria (BDD/GWT)
### Scenario 1: 범위 내 조회
- Given: 유효한 동의 scope다.
- When: Adapter를 조회한다.
- Then: 승인 필드만 처리하고 최소 감사 event를 남긴다.
### Scenario 2: 범위 초과
- Given: 동의 범위 밖 필드다.
- When: 조회를 시도한다.
- Then: 차단하고 오조회 플래그·중단 절차를 시작한다.
### Scenario 3: M1 로그
- Given: 계산 성공·실패가 발생한다.
- When: 로그를 검사한다.
- Then: calculation ID·result hash·Rule·시각·오류 코드만 있고 원본 금융 응답은 없다.
