## 저장소 구조

| 경로 | 역할 |
| --- | --- |
| `app/`, `features/` | Next.js 애플리케이션과 CardFit 기능 코드 |
| [`docs/product/`](docs/product/) | 최신 PRD와 SVG 다이어그램 |
| [`docs/technical/`](docs/technical/) | 최신 SRS와 기술 검토 기준 |
| [`docs/tasks/`](docs/tasks/) | TASK 기준선, 정책 로그, 개발 TASK |
| [`docs/plans/`](docs/plans/) | 실행 계획과 과거 계획 기록 |
| [`docs/decisions/`](docs/decisions/) | 인터뷰와 의사결정 이력 |
| [`docs/reports/`](docs/reports/) | 분석 보고서와 PNG 시각 자료 |
| `scripts/` | 검증 및 실행 보조 도구 |

구버전 PRD·SRS는 저장소 파일 트리에서 제거했으며 필요할 때 Git 이력에서 확인할 수 있습니다.
